# 📝 Daily Task Manager (To-Do App)

The Daily Task Manager is a simple yet functional To-Do web application built using **HTML, CSS, and JavaScript**.  
It allows users to manage their daily tasks efficiently by organizing them into **Pending Tasks** and **Completed Tasks** sections.

This project demonstrates DOM manipulation, event handling, and dynamic content updates using JavaScript.



## 📌 Project Overview

This To-Do web app allows users to:

- Add new daily tasks
- View tasks instantly after adding them
- Mark tasks as “Completed”
- Automatically move completed tasks to a separate section
- Edit existing tasks
- Delete tasks from either list
- View date and time when tasks are added (optional feature)
- View date and time when tasks are completed (optional feature)

The main To-Do list is a combination (union) of:

- ✅ Completed Tasks  
- ⏳ Pending Tasks  



## 🚀 Features
